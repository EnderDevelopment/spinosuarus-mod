# Spinosuarus Mod

Add a realistic Spinosuarus to your Minecraft world that swims and hunts fish.

## Features

- Adds a Spinosuarus entity that swims and spawns near rivers
- Spinosuarus hunts fish, adding a new dynamic to water ecosystems

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.14.0 or higher
- Fabric API 0.91.0 or higher

## Installation

1. Download the mod JAR file from the [releases page](https://github.com/EnderDevelopment/spinosuarus-mod/releases).
2. Place the JAR file in your `mods` folder.
3. Launch Minecraft with the Fabric profile.

## Usage

- Spinosuarus will spawn naturally near rivers.
- Use a Spinosuarus Spawn Egg to spawn one manually.

## Configuration

No additional configuration is required. The mod is ready to use out of the box.
